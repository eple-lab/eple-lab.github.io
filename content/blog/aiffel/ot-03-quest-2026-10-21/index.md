"우리 퀘스트 할 거예요. 던전에서 퍼실 몹을 잡을 겁니다. ^^"

공부하러 왔는데 던전이라니 ㅋ
아이펠에는 게임처럼 캐릭터를 고르고 던전에 들어가 **퍼실 몹**과 대결하는 **퀘스트**가 있다.
퀘스트가 뭔지, 그리고 직접 해 본 "퍼실 몹 잡기" 후기.

> **3줄 요약**
> - 퀘스트는 배운 내용을 확인하는 **미션**. 점수는 대시보드에 쌓여 **졸업 점수**에 들어간다.
> - 유형은 **팀 가르치기(A·B)**, **페어프로그래밍(C-1)**, **코드 피어리뷰(C-2)**, **메인 퀘스트**.
> - 선생팀으로 이겼지만 **"AI와 연결해서 더 많이 이야기했으면 좋았을걸"** 하는 아쉬움이 남았다.

## 퀘스트 용어

| 말 | 뜻 |
|---|---|
| **캐릭터** | 처음에 6가지 유형 중 하나를 고른다 |
| **스터디** | 퀘스트를 깨기 위해 공부하는 시간 |
| **던전** | 대결하러 들어가는 곳 (늦으면 0점!) |
| **퍼실 몹** | 던전에서 문제를 내는 퍼실님 |
| **대결 / 액션** | 공부한 걸로 몹과 붙어 통과하는 과정 |

퀘스트 내용과 내 팀은 시작 **5분 전**에 공개된다.

## 퀘스트 유형

| 유형 | 방식 | 포인트 |
|---|---|---|
| **A. 모두를 이해시켜라** | 선생팀 하나가 여러 학생팀을 가르침 | 학생팀이 통과하면 선생팀도 같은 점수 |
| **B. 타팀을 이해시켜라** | 선생팀과 학생팀이 1:1 | 퍼실 몹 문제 3개 중 2개 이상 맞히기 |
| **C-1. 페어프로그래밍** | 드라이버(코딩) + 네비게이터(조언) | 네비게이터는 키보드에 손대면 안 됨 |
| **C-2. 코드 피어리뷰** | 코더 + 리뷰어 | 답 대신 키워드로, 칭찬은 아낌없이 |
| **메인 퀘스트** | 모듈 마무리, **개인** 진행 | 검색 금지, 못 풀면 귀가 불가 😱 |

A와 B는 대결할 때 **채팅 없이 마이크로만** 설명해야 한다.
말로 설명할 수 있어야 진짜 이해한 거라는 뜻.

## 퍼실 몹 잡기: 선생팀 후기

내가 해 본 건 **퀘스트 A, 퍼실 몹 잡기**.
나는 **선생팀**이었고 주제는 **git**.

1. 선생팀이 먼저 git을 공부한다.
2. 학생팀에게 가르친다.
3. 학생팀이 던전에서 퍼실 몹의 문제를 푼다.(선생팀은 조언해줄 수 없다. ㄷㄷ)
4. 학생팀이 통과하면 선생팀도 같이 이긴다.

결과는 **승리**.
재미있었는데, 끝나고 나니 반성할 게 보였다.

## 이겼는데 반성한 이유

우리는 전반적으로 git의 **뜻과 명령어** 위주로 가르쳤다.
전반적으로 "**AI와 어떻게**" 라는 느낌으로 이야기했다면 더 좋았을거 같다. 

바이브 코딩에서는 AI가 코드를 고치고 사람은 결과를 판단한다.
그렇게 보면 git은 저장 명령어 이상이다.

- AI가 **무엇을 바꿨는지 비교**하는 도구
- 마음에 안 들면 **되돌리는** 안전장치
- **브랜치**로 AI에게 실험을 맡기는 공간/개별 업무를 진행하는 공간
- **커밋 메시지**로 AI가 한 일을 기록하는 습관

이렇게 **AI와 연결해서** 설명했다면 학생팀이 "그래서 git이 필요하구나" 하고 더 오래 기억했을 거다.
문제를 푸는 것과 **왜 배우는지 아는 것**은 다르다. 선생팀을 하면서 배웠다.

## 퀘스트를 해 보고

가르치는 쪽이 제일 많이 배운다는 말은 사실이었다.
다음에 선생팀을 맡으면 "**이게 AI랑 무슨 관계가 있을까?**"부터 설명해 봐야지.
