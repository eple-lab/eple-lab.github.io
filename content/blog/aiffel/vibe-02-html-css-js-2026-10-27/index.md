두 번째 날은 웹페이지를 **세 겹**으로 나눠 보는 연습.
문법을 깊게 파는 날이 아니라, AI가 만든 화면에서 **어디를 고쳐야 할지 짚는 눈**을 만드는 날이었다.

> **3줄 요약**
> - 웹페이지 = **구조(HTML) · 표현(CSS) · 동작(JavaScript)** 세 겹.
> - 겹을 지정해서 말하면 AI가 손댈 범위가 좁아지고, 괜찮던 부분이 덜 흔들린다.
> - 이름만으로 안 통하는 "내 게임"은 **화면·상태·규칙**을 내가 직접 적어야 한다.

## 세 겹, 각자 태어난 이유가 다르다

| 겹 | 태어난 문제 | 검토 기준 |
|---|---|---|
| HTML | 흩어진 정보를 연결하기 | 정보와 용어가 빠지지 않았나 |
| CSS | 내용과 꾸밈이 붙어 있어 수정이 번지는 문제 | 읽히나, 깨지는 폭은 없나 |
| JavaScript | 눌러도 반응 없는 정적인 문서 | 행동 뒤의 변화가 기대대로인가 |

"페이지 고쳐줘"는 어디를 고칠지 안 정한 요청이고,
"카드 정보는 그대로 두고 모바일 간격만 조정해줘"는 겹을 지정한 요청이다.

## 실습: 테트리스, 그리고 내 게임

1차는 채팅 AI에 **"테트리스 만들어줘."** 한 줄.
테트리스는 이름 자체가 규칙 명세서라서 한 줄로 통한다.
나는 이건 퍼실님이 작업한 걸로만 봤다.

2차는 내가 고른 게임. 이름만으로는 AI에게 안 통하니까 규칙을 내가 적는다.
나는 **반딧불이 게임**. 게임을 **보이는 것 · 상태 · 규칙**으로 나눠서 요청문을 썼다.

## 과제: GitHub Pages 배포 - AI가 멈춘 곳

과제는 만든 게임을 GitHub Pages에 올리고 링크 제출.

예전에는 내가 저장소를 직접 만들고, 콜라보레이터 넣고, 소스트리로 클론받고 했다.
이번엔 수업 들으면서 하느라 바빠서 Claude에게 맡겼다.

- 저장소 만들기와 푸시는 Claude가 했다.
- 그런데 **Pages 켜기**에서 멈췄다. gh(GitHub CLI)가 없어서.
- gh를 깔았더니 이번엔 **로그인**에서 멈췄다. 브라우저에서 계정을 승인하는 건 사람이 해야 하는 단계.
- 터미널에 `Authenticate Git with your GitHub credentials? (Y/n)`이 떴는데...
  **"이거 뭐라는 거야? Y 해야 돼? N 해야 돼?"** 계속 물어봤다 ㅎㅎㅎ
- 로그인한 뒤 Pages는 Claude가 켜고, 게임 첫 화면이 열리는 것까지 확인해 줬다.

수업에서 "배포 과정에서 AI가 멈추고 사람에게 넘긴 단계는?"이라고 물었는데, 나는 정확히 그 장면을 겪었다.

그리고 다음엔...
**cli로 설치는 꼭 손으로 해 보고 싶더라.**
