<!--more-->

## 만들 게임

밤하늘을 나는 팅커벨이 되어, 달빛 호수 숲에서 반딧불이 5마리를 투명한 유리병에 살포시 담는 게임입니다. 서두르면 반딧불이가 흩어지고, 천천히 다가가 손을 내밀어야 손등에 앉습니다.

## 게임을 이루는 세 가지 재료

| 재료 | 내 게임에서는 |
|---|---|
| 보이는 것 | 달빛 호수와 숲, 여러 모양의 나무, 팅커벨, 반딧불이, 유리병(0/5), 수호신 용, 새·사슴·토끼, 남은 시간, 화면 키 안내, 그만하기 버튼 |
| 상태 | 비행 속도(둥둥/느림/빠름), 반딧불이 반응(흩어짐/다가옴/손등/병 안), 따콩·나무 위 휴식, 담은 수, 남은 시간, 진행 중/일시정지/성공/종료 |
| 규칙 | 천천히 다가가 [ ] 로 손을 내밀면 반딧불이가 앉고, \ 로 병에 담는다. 빠르면 흩어진다. 나무에 부딪히면 따콩. 5마리면 성공, 3분이면 계속/그만 선택 |

## 요청문

```text
새 폴더 my-game을 만들고, 그 안에 아래 게임을 만들어줘.

만들 게임: 반딧불이 모으기 — 밤하늘을 나는 팅커벨이 되어 반딧불이를 투명한 유리병에 담는 게임

규칙:
팅커벨은 W/A/S/D로 위·왼쪽·아래·오른쪽으로 날아다니고, 방향키 ↑는 속도 올리기, ↓는 속도 낮추기야.
속도가 아주 낮으면 그 자리에 둥둥 떠 있는 상태가 돼.
반딧불이는 무리 지어 있기도 하고 혼자 날기도 하는데, 빠르게 다가가면 흩어지고,
천천히 다가가서 손을 올리면([ = 왼손, ] = 오른손) 반딧불이가 천천히 날아와 손등에 앉아.
손등에 앉은 상태에서 \ 키(엔터 위)를 누르면 손바닥으로 살포시 들어 올려 유리병에 담겨.
나무에 부딪히면 "따콩!" 소리가 나고 화면에도 글자와 튕기는 효과가 보여.
나무 위에 내려앉아 쉴 수도 있어.

끝나는 조건:
- 반딧불이 5마리를 병에 담으면 행복한 성공 문구가 나오고 게임이 끝나.
- 제한시간은 3분. 3분이 되면 "계속할까요? / 그만할까요?"를 물어봐줘.

파일은 index.html, styles.css, script.js 세 개로 나눠줘.

- 화면:
  - 무대: 달빛이 비치는 커다란 호수를 나무들이 둘러싼 여름밤 숲. 나무는 빽빽하지 않게.
  - 나무: 판타지처럼 아주 길고 큰 나무, 넓고 짧은 나무, 길고 가는 나무를 섞어서.
  - 생물: 밤에 날아다니는 새, 돌아다니는 사슴·토끼.
  - 호수의 수호신 용: 무섭지 않고 온화하고 예쁘고 따뜻한 느낌. 반딧불이가 용을 좋아해서 그 근처를 맴돌아.
  - 팅커벨, 반딧불이, 투명하고 귀여운 유리병(담긴 수 0/5가 병 안의 빛으로 보이게).
  - 남은 시간 표시.
  - 키 안내: W A S D, ↑ ↓, [ ], \ 키 모양을 화면에 보여주고, 누르는 동안 해당 키가 켜지게.
  - 오른쪽 위에 언제든 누를 수 있는 "그만하기" 버튼.
- 모바일에서도 조작하기 편한 크기로, 아래 상태가 색과 문구로 함께 보이게 해줘.
  - 비행 속도(둥둥 떠 있음 / 느림 / 빠름)
  - 반딧불이 반응(흩어짐 / 다가옴 / 손등에 앉음 / 병에 담김)
  - 나무에 부딪힘(따콩!), 나무에 앉아 쉬는 중
  - 병에 담긴 수(0~5)와 남은 시간
- 화면 전체가 들숨·날숨처럼 아주 천천히 위아래로 살짝 떠 있게 해줘. 눈이 피곤하지 않을 정도로 약하게.
- 게임 중 Ctrl+C를 누르거나 "그만하기" 버튼을 누르면 게임을 멈추고
  "계속할까요? / 그만할까요?" 화면을 보여줘. 3분이 됐을 때와 같은 화면이야.
- 내가 적은 규칙 그대로 동작하고, 끝나는 조건이 되면
  결과와 다시하기 버튼이 나오게 해줘.

규칙에 애매한 부분이 있으면 만들기 전에 나에게 물어봐.
완료 후 내가 브라우저에서 확인할 방법과 수정 체크리스트를 알려줘.
```

## 만들기 전에 정한 것

요청문 끝의 "애매하면 물어봐" 단계를 코드 전에 PRD 인터뷰로 끝냈습니다. 요청문과 달라진 부분이 생겨서, 바뀐 내용은 결정 기록으로 남겼습니다.

| 질문 | 결정 |
|---|---|
| 화면 시점 | 메인은 팅커벨 눈으로 보는 1인칭 3D, 오른쪽 위 작은 창은 3인칭 따라가기 |
| 방향키 역할 | W 위 / S 아래 / A·D 방향 돌리기, 앞으로 가는 빠르기는 ↑ ↓ |
| 나무에 앉기 | 멈춘 채 가지에 닿거나 나무 가까이에서 ↓ |
| 따콩 벌칙 | 손등의 반딧불이만 날아가고 1초 비틀거림 |
| 3분 뒤 계속 | 담은 반딧불이는 그대로, 3분 더 |
| Ctrl + C | 게임 중에는 복사 대신 멈춤 창 |
| 휴대폰 조작 | 화면 아래 키 버튼을 손가락으로 누르기 |
