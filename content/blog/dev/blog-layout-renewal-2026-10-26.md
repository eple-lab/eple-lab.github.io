Hextra 테마 위에 블로그 목록을 카드형으로 바꾸고, 카테고리·태그 사이드바와 소개 페이지, 프로젝트 문서를 더했습니다. 테마 파일은 건드리지 않고 덮어쓰기만으로 바꾼 과정을 정리합니다.

<!--more-->

## 원칙: 테마는 그대로, 덮어쓰기로

테마(`themes/hextra`)는 git submodule이라 직접 고치면 업데이트할 때 충돌이 납니다. Hugo는 프로젝트 폴더에 같은 경로의 파일이 있으면 그쪽을 먼저 쓰기 때문에, 바꾸고 싶은 부분만 프로젝트에 복사해서 고쳤습니다.

| 파일 | 역할 |
|---|---|
| `assets/css/custom.css` | 포인트 색, 카드, 사이드바 등 모든 스타일 |
| `layouts/blog/list.html` | 블로그 목록 |
| `layouts/blog/single.html` | 글 상세 |
| `layouts/term.html` | 카테고리·태그별 목록 |
| `layouts/about.html` | 소개 페이지 |
| `layouts/_partials/blog-layout.html` | 목록 화면 공통 틀 (사이드바 + 카드) |
| `layouts/_partials/blog-side.html` | 카테고리·태그 목록 조각 |

## 포인트 색: 민트

Hextra는 포인트 색을 CSS 변수 세 개로 정합니다. `#14b8a6`을 HSL로 바꿔 넣었습니다.

```css
:root,
.dark {
  --primary-hue: 173deg;
  --primary-saturation: 80%;
  --primary-lightness: 40%;
}
```

처음에는 `:root`에만 넣었더니 다크 모드에서 파란색 그대로였습니다. 테마가 `.dark`에서 색을 한 번 더 정하고 있어서 두 곳 모두 덮어써야 했습니다. 상단 메뉴와 사이드바 링크도 마우스를 올리면 민트로 바뀌게 했습니다.

## 블로그 목록: 카드형

목록을 카드로 바꿨습니다. 카드에는 제목, 카테고리 배지, 날짜와 읽는 시간, 요약 2줄, 태그가 들어갑니다. 처음에는 2열로 놓았는데, 글 순서가 왼쪽→오른쪽→다음 줄로 이어져서 어느 글이 최신인지 헷갈렸습니다. 그래서 한 줄에 카드 하나씩 길게 놓는 방식으로 바꿨습니다.

정렬에서 하나 걸린 점이 있었습니다. 글 날짜를 `2026-10-23`처럼 날짜만 적었더니, 같은 날 쓴 글끼리 순서가 들쭉날쭉했습니다. 처음에는 날짜가 같으면 마지막 커밋 시간으로 한 번 더 정렬했는데, 예전 글을 고치거나 여러 글을 한 커밋에 같이 고치면 순서가 다시 바뀌었습니다.

그래서 작성일과 수정일을 나눴습니다.

- **작성일** (`date`): 처음 쓴 날짜와 시간을 적고 바꾸지 않습니다. 목록은 이 값으로만 정렬합니다.
- **수정일** (`lastmod`): 내용을 실제로 고쳤을 때만 직접 적습니다. 적은 글에만 하단에 "마지막 수정 일자"가 나옵니다.

```yaml
date: 2026-10-26 14:30:00
lastmod: 2026-10-27 09:00:00  # 내용을 고쳤을 때만
```

```toml
timeZone = 'Asia/Seoul'  # 시간대를 적지 않아도 한국 시간으로 처리

[frontmatter]
  lastmod = ['lastmod', 'date']  # git 커밋 시간 대신 직접 적은 값, 없으면 작성일
```

## 카테고리·태그 사이드바

상단 메뉴에서 카테고리와 태그를 빼고, 블로그 왼쪽에 목록으로 넣었습니다.

- 카테고리는 글 수와 함께, 태그는 알약 모양으로 보여 줍니다.
- 카테고리를 누르면 같은 화면 틀 그대로 그 카테고리의 글만 나옵니다. 블로그 목록과 카테고리·태그 페이지가 `blog-layout.html` 하나를 같이 씁니다.
- 글 상세 페이지에도 왼쪽에 같은 목록을 두고, 지금 글이 속한 카테고리와 태그를 민트로 강조합니다. 오른쪽 목차는 그대로 둡니다.
- 휴대폰에서는 카테고리가 카드 위 가로줄로 바뀌고, 글 상세에서는 본문을 넓게 쓰도록 숨깁니다.

## 정렬 맞추기

사이드바를 넣고 보니 왼쪽에 큰 빈칸이 있었습니다. Hextra가 문서용 사이드바 자리를 블로그 페이지에서도 비워 두고 있었던 것입니다. 이 자리를 없애고 본문 좌우 여백을 상단 메뉴바와 같게 맞춰서, 사이드바 왼쪽 끝은 로고와, 카드 오른쪽 끝은 GitHub 아이콘과 딱 맞게 했습니다.

휴대폰에서는 카테고리 가로줄 때문에 카드가 화면 밖으로 살짝 밀려났습니다. 그리드 열을 `1fr` 대신 `minmax(0, 1fr)`로 바꿔 내용이 길어도 열이 줄어들 수 있게 해서 해결했습니다.

## 소개 페이지

이력을 바탕으로 About 페이지를 만들었습니다. 왼쪽 프로필 카드에 경력·프로젝트 수를 민트 동그라미로, 연락처를 아이콘 버튼으로, 기술 스택을 태그로 넣고, 오른쪽에 소개와 경력을 적었습니다. 블로그와 같은 폭과 여백을 쓰도록 전용 레이아웃을 두었습니다.
