news-pick은 별도 서버나 코드 없이 Claude Code 위에서 돌아갑니다. 두 파일이 핵심입니다.

| 파일 | 역할 |
|---|---|
| [`CLAUDE.md`](https://github.com/eple-lab/news-pick/blob/main/CLAUDE.md) | 에이전트의 역할, 타겟과 톤, 지켜야 할 규칙 |
| [`.claude/skills/news-package/SKILL.md`](https://github.com/eple-lab/news-pick/blob/main/.claude/skills/news-package/SKILL.md) | `/news-package [키워드]`로 실행하는 처리 순서와 출력 형식 |

## 실행

```text
/news-package AI 에이전트
```

키워드를 비워 두면 기본값(AI, 에이전트, 자동화)으로 찾습니다.

## 처리 순서

과제에서 정리한 알고리즘(키워드 입력 → 크롤링·요약 → 캡션 결합 → 패키지 출력)을 실행할 수 있게 8단계로 나눴습니다.

{{% steps %}}

### 키워드·소스 확인

키워드가 없으면 기본값을 씁니다.

### 뉴스 수집

웹 검색으로 최근 24시간 기사를 찾고, 부족하면 3일까지 넓힌 뒤 넓혔다는 사실을 밝힙니다. 신뢰할 수 있는 언론사와 공식 발표를 우선하고, 여러 언론사가 함께 다룬 이슈를 이슈도가 높다고 봅니다. 고른 기사는 원문을 직접 열어 날짜와 내용을 확인합니다.

### 중복 제거·필터

같은 이슈는 하나로 묶고, `data/history.md`를 읽어 최근 14일 안에 다룬 이슈는 뺍니다.

### 요약·인사이트

기사 3개를 골라 각각 직접 쓴 3줄 요약과 핵심 포인트 1개를 만듭니다.

### 캡션 결합

정해진 출력 형식에 맞춰 하나의 캡션으로 묶습니다.

### 자동 검증

아래 체크리스트를 스스로 점검하고, 통과하지 못한 항목은 고친 뒤 다시 점검합니다.

### 사람 검수 요청

발행 전에 사용자가 기사 원문으로 사실관계를 확인해야 한다는 한 줄을 붙입니다.

### 저장·기록

결과를 `output/YYYY-MM-DD.md`에 저장하고, `data/history.md` 표에 이번 뉴스 3건을 추가합니다.

{{% /steps %}}

## 출력 형식

설명(선정 이유, 가정, 검증 결과)과 캡션 본문을 나눠서 보여 줍니다. 캡션 본문은 코드 블록 하나에 담아 그대로 복사할 수 있게 합니다.

1. 훅 (첫 줄, 한 문장)
2. 뉴스 3개: 제목 / 3줄 요약 / 핵심 포인트 / 출처
3. 학습자 관점 한 줄
4. 콜투액션 (저장, 공유, 댓글 유도 중 하나)
5. 해시태그 5~10개
6. 링크 안내: 캡션에는 "링크는 프로필 또는 댓글 참고"로 쓰고, 링크 목록은 캡션 밖에 따로 제공

## 검증 체크리스트

모두 통과해야 완성입니다.

- [ ] 뉴스 3개 모두 출처와 링크가 있다
- [ ] 요약은 원문 문장이 아니라 직접 쓴 문장이며, 원문에 없는 내용이 없다
- [ ] 캡션 길이가 1,500자 이내이고(인스타 한도 2,200자), 해시태그가 5~10개다
- [ ] 첫 줄 훅과 마지막 콜투액션이 있다
- [ ] 같은 뉴스를 최근 14일 안에 다룬 적이 없다

## 지키는 규칙

- 기사 문장을 그대로 옮기지 않습니다. 인용이 필요하면 15단어 미만으로 짧게, 출처를 밝힙니다.
- 확인되지 않은 내용은 단정하지 않고 "보도에 따르면"으로 씁니다.
- 사용자의 경력이나 신상 정보는 콘텐츠에 넣지 않고, 사용자가 직접 알려준 관점만 씁니다.
- 정보가 부족하면 가정을 한 줄로 밝히고 먼저 만듭니다. 질문은 한 번에 하나만 합니다.
