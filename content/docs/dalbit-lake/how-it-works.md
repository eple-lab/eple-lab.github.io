## 반딧불이 모으기

👉 [플레이](https://eple-lab.github.io/dalbit-lake/fireflies/)

### 화면

- **메인 화면**: 요정의 눈으로 보는 1인칭 3D. 화면 가장자리에 손끝과 발끝이 은근히 보입니다.
- **오른쪽 위 작은 창**: 요정의 왼쪽 위에서 비스듬히 내려다보며 따라가는 3인칭 화면입니다.
- **무대**: 작은 호수 가운데를 온화한 수호신 용이 헤엄치고, 땅 위 나무 12그루와 물에서 솟은 나무 세 그루, 반딧불이 70마리, 사슴·토끼·새가 있습니다.
- **아래쪽 키 안내**: 누르고 있는 키에 불이 켜집니다. 휴대폰에서는 이 버튼을 손가락으로 누릅니다.

### 조작

| 키 | 동작 |
|---|---|
| W / S | 위로 / 아래로 |
| A / D, ← / → | 왼쪽 / 오른쪽으로 방향 돌리기 |
| ↑ / ↓ | 앞으로 / 뒤로. 오래 누를수록 빨라지고, 떼면 점점 느려짐. 나무 가까이에서 ↓ 는 가지에 앉기 |
| [ / ] | 왼손 / 오른손 내밀기 (누르고 있는 동안) |
| \ (엔터 위) | 손등의 반딧불이를 병에 담기 |
| Ctrl + C, Esc, 오른쪽 위 "그만하기" | "계속할까요 / 그만할까요" 창 |

### 규칙

{{% steps %}}

### 천천히 다가가기

빠른 속도(주황)로 다가가면 반딧불이가 흩어집니다.

### 손 내밀기

근처에 반딧불이가 있으면 "손을 올려보세요" 안내가 나옵니다. [ 또는 ]를 누르고 있으면 가장 가까운 반딧불이가 밝게 빛나며 천천히 날아와 손등에 앉습니다.

### 병에 담기

손등에 앉으면 \ 를 누릅니다. 두 손으로 감싸 투명한 병에 넣습니다.

### 끝

5마리를 담으면 성공 문구가 나옵니다. 제한시간 3분이 되면 계속할지 묻고, 계속하면 담은 반딧불이는 그대로 두고 3분을 더 줍니다.

{{% /steps %}}

**그 밖의 규칙**

- **따콩!**: 나무에 부딪히면 소리와 함께 튕겨 나가고 1초 비틀거립니다. 손등의 반딧불이만 날아가고 병 속 반딧불이는 그대로입니다.
- **쉬기**: 나무 가까이에서 ↓ 로 가지에 앉습니다. 이동 키나 ↑ 를 누르면 다시 날아오릅니다.
- **용**: 반딧불이는 용을 좋아해 그 곁에 많이 모입니다. 다가가면 용이 쳐다보며 눈을 가늘게 뜨고 반깁니다.

### 파일 (세 겹)

| 파일 | 겹 | 내용 |
|---|---|---|
| `index.html` | 구조 | 시작·멈춤·성공 화면, 위쪽 정보, 아래 키 안내 |
| `styles.css` | 표현 | 색, 배치, 눌린 키 표시, 따콩 애니메이션, 휴대폰 크기 |
| `script.js` | 동작 | 3D 장면, 비행, 반딧불이, 손·병 동작, 소리, 진행 |

- 3D는 [Three.js](https://threejs.org/)를 CDN에서 불러오고, 이미지·모델 파일 없이 도형을 코드로 조합했습니다.
- 소리는 파일 없이 브라우저(Web Audio)에서 만듭니다.

## 별빛 받기

👉 [플레이](https://eple-lab.github.io/dalbit-lake/starlight/)

| 떨어지는 것 | 받으면 |
|---|---|
| ⭐ 하얀 별 | +1점 |
| 🌟 황금 별 | +5점 |
| 🟣 그림자 방울 | 달 하나를 잃음 (3개를 모두 잃으면 끝) |

- 연속으로 5개를 담을 때마다 점수 배율이 1씩 오르고, 별을 놓치면 연속 기록이 0이 됩니다.
- 시간이 갈수록 별이 빨리, 자주 떨어지고 그림자 방울도 늘어납니다.
- 조작: ← → 또는 A D, 마우스·터치로 배 이동. Space·Enter로 시작, Esc나 "그만하기"로 처음 화면.
- 파일: `index.html` 하나에 화면·스타일·코드가 모두 들어 있습니다 (캔버스 2D).
