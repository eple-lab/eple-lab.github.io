# 블로그 시작하기

이 사이트는 [Hugo](https://gohugo.io/)와 [Hugo Book](https://github.com/alex-shpak/hugo-book) 테마로 만들었고, GitHub Actions로 GitHub Pages에 배포됩니다.

## 새 문서 추가

## 새 글 추가

`content/posts/` 아래에 마크다운 파일을 추가하면 블로그 목록에 나타납니다.
